BEHIND THE JOURNEY

The beauty of falling.

What if you could drop into a tunnel in Cape Town and coast all the way to Zurich?

Gravity accelerates you as you descend. As you climb toward your destination, that speed turns back into height. In this ideal model, you arrive at the surface at rest—without an engine.

Deeper can mean faster.

The shortest tunnel is a straight chord. The fastest is generally a brachistochrone: a hypocycloid that dives more steeply, gaining speed earlier. For antipodal points, the two routes become the same diameter.

T = √[ R/g · θ(2π − θ) ]θ is the central angle in radians · R = 6,371 km · g = 9.80665 m/s²

The rules of this little universe

  • A spherical Earth with uniform density and no rotation.
  • An evacuated, frictionless tunnel with ideal guidance and no propulsion.
  • Departure and arrival at the surface, at rest.
  • Geological layers provide visual context; their densities are not used in the calculation.

This is a physics visualization. Earth’s actual density profile changes the optimal curve and travel time. Heat, pressure, excavation, and engineering feasibility are outside this model.

FOR THE CURIOUS & THE BUILDERS

Your route. Your code.

The same physics engine, with an API to explore it.

Browser engine ready. Checking optional API…

The HTML app runs entirely in your browser, including on GitHub Pages. Start the included Node server to expose the REST endpoints. The browser API is always available as window.ThroughEarth.

GET/api/v1/route 
Run the request to see your route.

Endpoints

GET /api/v1/routeCity IDs or latitude,longitude
POST /api/v1/routeOrigin and destination as JSON
GET /api/v1/locations?q=Search the city catalogue
GET /api/v1/healthAPI status and model version

Use it directly in the browser

const route = ThroughEarth.calculate({
  origin: { lat: -33.9249, lon: 18.4241 },
  destination: { lat: 47.3769, lon: 8.5417 },
  mode: "fastest", samples: 241
});
console.log(route.travel_time_seconds);
Download the OpenAPI specification ↓

No API key required by the local server. Input validation and CORS are included. API path samples are equally spaced in physical time, in Earth-radius units.
